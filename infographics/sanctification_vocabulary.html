“Sanctification” is a New Testament nounThe noun appears in 5 verses, all in the New Testament. The Old Testament only ever uses the verb: “sanctify” is in 59 Old Testament verses.
“Hallow” almost vanishes33 of the 35 “hallow” verses are in the Old Testament. The other 2 are the same prayer, twice: “Hallowed be thy name” (Matthew 6:9, Luke 11:2).
“Consecrate” is a priestly word38 of its 40 verses are Old Testament, most about ordaining priests. Its two New Testament uses are both in Hebrews, and both are about Christ.
“Holiness” is the most even30 Old Testament and 13 New Testament verses: about a third New Testament, against roughly a fifth for the set as a whole.

Neighbouring words, searched but left out

These words often appear alongside sanctification, but most of their uses are about something else: ritual washing, leprosy, the Nazarite vow, dividing land. They are counted here for comparison and are not in the 240-verse set. “Holy” is left out for the same reason: it is in 549 verses, but 89 of those are “Holy Ghost”, 63 “holy place” and 52 “Holy One”: mostly names and places, not the act of making holy.

The queries

The 240-verse set used on all five pages

SELECT b.name AS book, v.chapter, v.verse, v.text
FROM KJV_verses v
JOIN KJV_books b ON b.id = v.book_id
WHERE (v.text LIKE '%sanctif%' OR v.text LIKE '%hallow%' OR v.text LIKE '%consecrat%'
       OR v.text LIKE '%holiness%' OR v.text LIKE '%holily%')
ORDER BY v.book_id, v.chapter, v.verse

Run this query in Datasette Lite, loaded directly from data/KJV.db in this repository. LIKE is case-insensitive for ASCII in SQLite, so “Sanctify” and “sanctify” both match. sanctif catches sanctify, sanctified, sanctifieth and sanctification without catching “sanctuary”.

Verses per word family, split by Testament (all three bar charts’ families)

SELECT w.word, COUNT(*) AS verses,
       SUM(v.book_id <= 39) AS ot, SUM(v.book_id >= 40) AS nt
FROM (SELECT 1 AS ord, 'sanctify (sanctif-)' AS word, '%sanctif%' AS pat
      UNION ALL SELECT 2, 'hallow', '%hallow%'
      UNION ALL SELECT 3, 'consecrate (consecrat-)', '%consecrat%'
      UNION ALL SELECT 4, 'holiness', '%holiness%'
      UNION ALL SELECT 5, 'holily', '%holily%'
      UNION ALL SELECT 6, 'saint(s)', '%saint%'
      UNION ALL SELECT 7, 'separate (separat-)', '%separat%'
      UNION ALL SELECT 8, 'cleanse (cleans-)', '%cleans%'
      UNION ALL SELECT 9, 'purify (purif-)', '%purif%'
      UNION ALL SELECT 10, 'blameless', '%blameless%'
      UNION ALL SELECT 11, 'undefiled', '%undefiled%'
      UNION ALL SELECT 12, 'unblameable', '%unblameab%') w
JOIN KJV_verses v ON v.text LIKE w.pat
GROUP BY w.ord, w.word
ORDER BY w.ord

Run this query in Datasette Lite, loaded directly from data/KJV.db in this repository. Books 1–39 are the Old Testament and 40–66 the New. A verse is counted once per family it contains, however many times the word occurs in it.

The sanctify family, form by form

SELECT w.form, COUNT(*) AS verses,
       SUM(v.book_id <= 39) AS ot, SUM(v.book_id >= 40) AS nt
FROM (SELECT 1 AS ord, 'sanctify' AS form
      UNION ALL SELECT 2, 'sanctified'
      UNION ALL SELECT 3, 'sanctifieth'
      UNION ALL SELECT 4, 'sanctification') w
JOIN KJV_verses v ON v.text LIKE '%' || w.form || '%'
GROUP BY w.ord, w.form
ORDER BY w.ord

Run this query in Datasette Lite, loaded directly from data/KJV.db in this repository. Each form is a distinct substring (“sanctify” does not match “sanctified”), so no verse is double-counted within a form.

Why “holy” is left out

SELECT COUNT(*) AS verses,
       SUM(v.text LIKE '%Holy Ghost%') AS holy_ghost,
       SUM(v.text LIKE '%holy place%') AS holy_place,
       SUM(v.text LIKE '%Holy One%') AS holy_one
FROM KJV_verses v
WHERE v.text LIKE '%holy%'

Verses using two families — the 4 verses above

SELECT b.name AS book, v.chapter, v.verse, v.text,
       (v.text LIKE '%sanctif%') + (v.text LIKE '%hallow%') + (v.text LIKE '%consecrat%')
       + (v.text LIKE '%holiness%') + (v.text LIKE '%holily%') AS families
FROM KJV_verses v
JOIN KJV_books b ON b.id = v.book_id
WHERE (v.text LIKE '%sanctif%' OR v.text LIKE '%hallow%' OR v.text LIKE '%consecrat%'
       OR v.text LIKE '%holiness%' OR v.text LIKE '%holily%')
  AND families >= 2
ORDER BY v.book_id, v.chapter, v.verse

Run this query in Datasette Lite, loaded directly from data/KJV.db in this repository. Each LIKE comparison returns 1 or 0, so adding them counts how many families a verse uses.
