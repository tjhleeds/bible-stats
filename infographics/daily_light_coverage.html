The SQLQueries used to compute every figure on this page

Every query below joins data/KJV.db and data/daily_light.db via ATTACH DATABASE. Datasette's hosted SQL runner (including Datasette Lite) rejects ad-hoc ATTACH statements for security reasons — cross-database queries there require a local server started with --crossdb, which the hosted tool doesn't offer. Run the query as shown, locally, to reproduce a figure exactly (Python's sqlite3 module). Each block below also splits the same computation into two single-database queries — one against each file, runnable online in Datasette Lite — with a note on how to reconcile them by hand into the same answer.

Books covered → 62 / 66 · 93.9%
-- Any book with at least one dl_reading_verses row referencing it
ATTACH DATABASE 'data/KJV.db' AS kjv;

SELECT
    (SELECT COUNT(DISTINCT b.id)
     FROM kjv.KJV_books b
     JOIN dl_reading_verses rv ON rv.kjv_book_name = b.name) AS books_covered,
    (SELECT COUNT(*) FROM kjv.KJV_books) AS total_books;
Manually cross-check online (two single-database queries)
KJV.db — all 66 book names 
SELECT name FROM KJV_books ORDER BY name
daily_light.db — distinct referenced book names 
SELECT DISTINCT kjv_book_name FROM dl_reading_verses ORDER BY kjv_book_name

Compare the two lists by eye: the 4 names in the first list but missing from the second are exactly the "no readings at all" books shown above.

Chapters covered → 726 / 1,189 · 61.1%
-- A chapter counts as "covered" if any verse in it is referenced
ATTACH DATABASE 'data/KJV.db' AS kjv;

SELECT COUNT(*) AS chapters_covered FROM (
    SELECT DISTINCT v.book_id, v.chapter
    FROM kjv.KJV_verses v
    JOIN kjv.KJV_books b ON b.id = v.book_id
    JOIN dl_reading_verses rv
        ON rv.kjv_book_name = b.name
       AND rv.chapter = v.chapter
       AND v.verse BETWEEN rv.verse_start AND COALESCE(rv.verse_end, rv.verse_start)
);
-- total chapters: SELECT COUNT(*) FROM (SELECT DISTINCT book_id, chapter FROM kjv.KJV_verses) -> 1189
Manually cross-check online (two single-database queries)
KJV.db — every real chapter, with its highest verse number 
SELECT b.name AS book, v.chapter, MAX(v.verse) AS max_verse
FROM KJV_verses v
JOIN KJV_books b ON b.id = v.book_id
GROUP BY b.name, v.chapter
ORDER BY b.name, v.chapter
daily_light.db — every reference (book, chapter, verse range) 
SELECT kjv_book_name, chapter, verse_start, verse_end
FROM dl_reading_verses
ORDER BY kjv_book_name, chapter, verse_start

A (book, chapter) pair only counts as covered if some reference's verse_start is ≤ that chapter's max_verse above — matching by chapter number alone overcounts by one: Judges 17:18 is referenced, but Judges 17 only has 13 verses, so that reference doesn't land on a real verse (727 naive matches vs. the correct 726).

Verses covered → 3,461 / 31,102 · 11.1%
ATTACH DATABASE 'data/KJV.db' AS kjv;

SELECT
    COUNT(DISTINCT v.id)                    AS covered_verses,
    (SELECT COUNT(*) FROM kjv.KJV_verses)   AS total_verses,
    ROUND(100.0 * COUNT(DISTINCT v.id)
        / (SELECT COUNT(*) FROM kjv.KJV_verses), 2) AS pct_covered
FROM kjv.KJV_verses v
JOIN kjv.KJV_books b ON b.id = v.book_id
JOIN dl_reading_verses rv
    ON rv.kjv_book_name = b.name
   AND rv.chapter = v.chapter
   AND v.verse BETWEEN rv.verse_start AND COALESCE(rv.verse_end, rv.verse_start);
Manually cross-check online (two single-database queries)
KJV.db — every verse 
SELECT b.name AS book, v.chapter, v.verse, v.text
FROM KJV_verses v
JOIN KJV_books b ON b.id = v.book_id
ORDER BY b.name, v.chapter, v.verse
daily_light.db — every reference (as verse ranges) 
SELECT kjv_book_name, chapter, verse_start, verse_end
FROM dl_reading_verses
ORDER BY kjv_book_name, chapter, verse_start

Expand each reference's range against the verse list above (dropping any, like Judges 17:18, that don't land on a real verse), then de-duplicate — overlapping references shouldn't double-count a verse. That reconciliation is exactly what the full query does in one step.

Words covered → 81,542 / 791,184 · 10.3% (approx., by whitespace count)
ATTACH DATABASE 'data/KJV.db' AS kjv;

WITH covered AS (
    SELECT DISTINCT v.id, v.text
    FROM kjv.KJV_verses v
    JOIN kjv.KJV_books b ON b.id = v.book_id
    JOIN dl_reading_verses rv
        ON rv.kjv_book_name = b.name
       AND rv.chapter = v.chapter
       AND v.verse BETWEEN rv.verse_start AND COALESCE(rv.verse_end, rv.verse_start)
)
SELECT
    SUM(LENGTH(text) - LENGTH(REPLACE(text, ' ', '')) + 1) AS covered_words,
    (SELECT SUM(LENGTH(text) - LENGTH(REPLACE(text, ' ', '')) + 1)
     FROM kjv.KJV_verses)               AS total_words
FROM covered;
Manually cross-check online (two single-database queries)
KJV.db — every verse's text 
SELECT b.name AS book, v.chapter, v.verse, v.text
FROM KJV_verses v
JOIN KJV_books b ON b.id = v.book_id
ORDER BY b.name, v.chapter, v.verse
daily_light.db — every reference (as verse ranges) 
SELECT kjv_book_name, chapter, verse_start, verse_end
FROM dl_reading_verses
ORDER BY kjv_book_name, chapter, verse_start

Same reconciliation as "Verses covered" above, then sum whitespace-based word counts (LENGTH(text) - LENGTH(REPLACE(text, ' ', '')) + 1) over the resulting de-duplicated verse set.

Old vs. New Testament split → OT 6.7% · NT 24.1%
-- KJV_books.id 1-39 = Old Testament (Genesis..Malachi), 40-66 = New Testament
ATTACH DATABASE 'data/KJV.db' AS kjv;

SELECT
    CASE WHEN b.id <= 39 THEN 'Old Testament' ELSE 'New Testament' END AS testament,
    COUNT(DISTINCT v.id) AS total_verses,
    COUNT(DISTINCT CASE WHEN rv.id IS NOT NULL THEN v.id END) AS covered_verses
FROM kjv.KJV_verses v
JOIN kjv.KJV_books b ON b.id = v.book_id
LEFT JOIN dl_reading_verses rv
    ON rv.kjv_book_name = b.name
   AND rv.chapter = v.chapter
   AND v.verse BETWEEN rv.verse_start AND COALESCE(rv.verse_end, rv.verse_start)
GROUP BY testament;
Manually cross-check online (two single-database queries)
KJV.db — total verses per testament 
SELECT CASE WHEN b.id <= 39 THEN 'Old Testament' ELSE 'New Testament' END AS testament,
    COUNT(*) AS total_verses
FROM KJV_verses v
JOIN KJV_books b ON b.id = v.book_id
GROUP BY testament
daily_light.db — every reference (as verse ranges) 
SELECT kjv_book_name, chapter, verse_start, verse_end
FROM dl_reading_verses
ORDER BY kjv_book_name, chapter, verse_start

Classify each reference's book as OT/NT using the "Books covered" query's book list above (Genesis–Malachi = OT, Matthew–Revelation of John = NT), reconcile against real verses as in "Verses covered," then count distinct covered verses per testament.

Per-book breakdown → powers the top-10 chart and the full table above
ATTACH DATABASE 'data/KJV.db' AS kjv;

SELECT
    b.id, b.name,
    COUNT(DISTINCT v.id) AS total_verses,
    COUNT(DISTINCT CASE WHEN rv.id IS NOT NULL THEN v.id END) AS covered_verses,
    ROUND(100.0 * COUNT(DISTINCT CASE WHEN rv.id IS NOT NULL THEN v.id END)
        / COUNT(DISTINCT v.id), 2) AS pct_covered
FROM kjv.KJV_books b
JOIN kjv.KJV_verses v ON v.book_id = b.id
LEFT JOIN dl_reading_verses rv
    ON rv.kjv_book_name = b.name
   AND rv.chapter = v.chapter
   AND v.verse BETWEEN rv.verse_start AND COALESCE(rv.verse_end, rv.verse_start)
GROUP BY b.id, b.name
ORDER BY b.id;
Manually cross-check online (two single-database queries)
KJV.db — total verses per book 
SELECT b.id, b.name, COUNT(*) AS total_verses
FROM KJV_verses v
JOIN KJV_books b ON b.id = v.book_id
GROUP BY b.id, b.name
ORDER BY b.id
daily_light.db — every reference (as verse ranges) 
SELECT kjv_book_name, chapter, verse_start, verse_end
FROM dl_reading_verses
ORDER BY kjv_book_name, chapter, verse_start

Reconcile each book's references against real verses as in "Verses covered" above, count distinct covered verses per book, then divide by the totals here.
