The queries

Sanctification verses per book, with density

SELECT b.name AS book, COUNT(*) AS verses_in_book,
       SUM((v.text LIKE '%sanctif%' OR v.text LIKE '%hallow%' OR v.text LIKE '%consecrat%'
           OR v.text LIKE '%holiness%' OR v.text LIKE '%holily%')) AS sanctification_verses,
       ROUND(1000.0 * SUM((v.text LIKE '%sanctif%' OR v.text LIKE '%hallow%' OR v.text LIKE '%consecrat%'
           OR v.text LIKE '%holiness%' OR v.text LIKE '%holily%')) / COUNT(*), 1) AS per_1000
FROM KJV_verses v
JOIN KJV_books b ON b.id = v.book_id
GROUP BY b.id, b.name
ORDER BY b.id

Run this query in Datasette Lite, loaded directly from data/KJV.db in this repository. Each LIKE comparison returns 1 or 0, so SUM of the combined condition counts matching verses per book. Books with no match return 0, not a missing row.

Hotspot chapters (four or more verses)

SELECT b.name AS book, v.chapter, COUNT(*) AS sanctification_verses
FROM KJV_verses v
JOIN KJV_books b ON b.id = v.book_id
WHERE (v.text LIKE '%sanctif%' OR v.text LIKE '%hallow%' OR v.text LIKE '%consecrat%'
       OR v.text LIKE '%holiness%' OR v.text LIKE '%holily%')
GROUP BY b.id, b.name, v.chapter
HAVING COUNT(*) >= 4
ORDER BY sanctification_verses DESC, b.id, v.chapter

The 240-verse set itself

SELECT b.name AS book, v.chapter, v.verse, v.text
FROM KJV_verses v
JOIN KJV_books b ON b.id = v.book_id
WHERE (v.text LIKE '%sanctif%' OR v.text LIKE '%hallow%' OR v.text LIKE '%consecrat%'
       OR v.text LIKE '%holiness%' OR v.text LIKE '%holily%')
ORDER BY v.book_id, v.chapter, v.verse
