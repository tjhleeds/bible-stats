The two books use the word quite differently. Proverbs never says "Blessed be the Lord" — not once in its 8 verses; blessing there is almost always something seen in a life, in children, a wife, a reputation, a memory. Psalms splits nearly evenly between pronouncing someone blessed (21 verses) and blessing God in return (17). Between them the two books hold 55 of the 290 "blessed" verses in the whole KJV.

The queries

Every "blessed" verse in Psalms and Proverbs — the 55 verses above

SELECT b.name AS book, v.chapter, v.verse, v.text
FROM KJV_verses v
JOIN KJV_books b ON b.id = v.book_id
WHERE b.name IN ('Psalms', 'Proverbs')
  AND v.text LIKE '%blessed%'
ORDER BY v.book_id, v.chapter, v.verse

Run this query in Datasette Lite, loaded directly from data/KJV.db in this repository. LIKE is case-insensitive for ASCII in SQLite, so this catches both "Blessed" and "blessed". Grouping into the nine themes above is editorial, done by reading the 55 results — it is not in the query.

The beatitudes — 21 verses

SELECT b.name AS book, v.chapter, v.verse, v.text
FROM KJV_verses v
JOIN KJV_books b ON b.id = v.book_id
WHERE b.name IN ('Psalms', 'Proverbs')
  AND (v.text LIKE '%lessed is%' OR v.text LIKE '%lessed are%')
ORDER BY v.book_id, v.chapter, v.verse

Run this query in Datasette Lite. Matching on lessed without its first letter keeps both sentence-initial "Blessed" and mid-sentence "blessed" (as in Psalm 34:8) without needing two more patterns.

The doxologies — 16 of the 17

SELECT b.name AS book, v.chapter, v.verse, v.text
FROM KJV_verses v
JOIN KJV_books b ON b.id = v.book_id
WHERE b.name IN ('Psalms', 'Proverbs')
  AND v.text LIKE '%Blessed be%'
ORDER BY v.book_id, v.chapter, v.verse

Run this query in Datasette Lite. It returns 16 rows; Psalm 119:12 is counted as the seventeenth doxology here because it addresses God directly ("Blessed art thou, O Lord") rather than describing anyone as blessed.
